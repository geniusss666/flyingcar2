01

安全目标与分析范围Safety Objectives and Scope

载人航空器安全的核心目标是：在全寿命周期内，把人员伤亡与重大财产损失的风险控制在可接受水平，并在任一单点失效发生后仍能进入安全状态（续飞、备降或应急降落）。EH216-S 作为无机载飞行员、自主飞行的载人 eVTOL，其安全责任由飞控系统、地面运营方与监管体系共同承担。

分析边界

  • 航空器本体：机体结构、动力推进（电机、旋翼、电池）、飞控与航电、导航感知、乘员舱与应急设备。
  • 地面控制站：指挥调度、状态监测、预警、集群管理与人工介入通道。[2]
  • 数据链路：航空器与地面站之间的通信链路及其冗余、完整性与抗干扰能力。
  • 运行环境：低空空域、气象条件、起降场地、地面第三者（地面人员与财产）以及与其他航空器 / 鸟类的冲突。

分析方法链条

STEP 1

危险源识别

按子系统列出危险源、触发场景与潜在后果（HAZID）。

STEP 2

失效分析

梳理失效模式、原因、影响与现行补偿措施（FMEA）。

STEP 3

风险定级

按严重度 × 概率构成风险矩阵，划分可接受 / 需缓解 / 不可接受区。

STEP 4

因果建模

以顶事件为顶向下建树，定位共因失效与关键底事件（FTA）。

STEP 5

功能安全复盘

补充预期功能安全（SOTIF）视角，识别未知与边缘场景风险。

分析立场 本文为课程层面的系统安全工程演练，基于公开文件与企业披露重建安全逻辑；不替代适航当局审定、制造商正式 FMEA/FTA 文件或运行风险评估。文中严重度与概率分级为教学口径，不代表官方安全完整性等级评定。
02

法规与标准框架Regulatory and Standards Framework

EH216-S 的安全合规建立在"专用条件 + 四证链条"之上：CAAC 针对载人无人驾驶航空器制定专用条件，航空器依次通过设计审定、生产批准、单机适航与运营准入，才能投入载人商业运行。[1][4]

层级文件 / 证书安全含义
审定基础CAAC《EH216-S 型无人驾驶航空器系统专用条件》（PEU.A005 类载人无人驾驶航空器）明确构型、乘员、飞控、动力、链路与应急等审定条款，是整机安全设计与验证的基准。[1]
型号合格证 TC2023-10 取得（全球首张载人无人驾驶 eVTOL TC）型号设计符合审定基础，安全设计与验证资料通过审查。
标准适航证 AC2023-12 首批取得单机制造符合已批准设计，处于适航可用状态。
生产许可证 PC2024-04 取得质量体系保证批量生产的航空器持续符合设计要求。
运营合格证 OC2025-03 起由持牌运营方取得运营方具备人员、程序、培训与运行控制能力，安全责任延伸到运行环节。[6]
国际参照EASA SC-VTOL（垂直起降航空器专用规范）、FAA Powered-Lift 框架；ISO 21448（SOTIF）用于横向对照安全目标、冗余等级与预期功能安全方法；EH216-S 具体符合性以中国审定文件为准。
框架要点 取证只证明"在批准的设计、生产与运行边界内满足安全基准"，不等于覆盖所有未知场景；运行安全还受气象边界、空域条件、维护质量与人员操作等持续因素影响。
03

系统安全架构分解Safety Architecture Decomposition

EH216-S 的安全架构以冗余、容损、故障安全（Fail-Safe）与应急兜底为主线：关键通道多套备份，故障时无缝切换；机载健康状态实时监测，自主判断续飞或应急就近降落；末端配备整机降落伞作为最后一道兜底。[2][10]

子系统安全设计措施（公开口径）设计意图
飞控与航电三套独立飞控并行，传感器多套配置，通过投票机制仲裁输出避免单通道 / 单传感器错误信号直接控制航空器；单点故障不导致失控。[1]
动力推进八轴十六旋翼分布式布局；飞控、动力、电池等关键部件全备份单个电机 / 旋翼失效后其余单元补偿推力，维持姿态并安全降落。[3]
能源系统12 组动力电池分组供电；关键能源通道备份单组电池异常时隔离故障组，保障剩余能量完成安全着陆。
健康管理Fail-Safe 系统实时监测航空器健康状态，智能判断续飞或应急就近降落故障早期识别，自动进入安全状态，降低人为反应延迟风险。[2]
应急兜底整机降落伞系统在常规气动控制与动力补偿不足时，降低坠落速度与地面冲击后果。[10]
通信与监控地面指挥调度系统与航空器、地面站实时数据交互，集中监测、预警与集群管理地面掌握飞行状态，异常时可按程序介入；链路状态纳入健康监控。[2]
结构与乘员碳纤维机身；旋翼布置于机身下方形成托举；乘员舱与座椅按载人约束设计减轻结构重量并降低旋翼侵入乘员舱的概率，提升乘员防护。[3]

单个电机 / 旋翼停转 / 转速骤降 / 桨叶断裂电机故障、桨叶疲劳或异物打击单侧推力损失，姿态倾斜，需其余旋翼补偿S4 严重 分布式动力容损；飞控重分配推力；单动力单元失效试验已通过验证。[11]

飞控通道单通道失效 / 输出与其余通道不一致硬件故障、软件异常、供电异常若未被仲裁排除，可能产生错误控制指令S4 严重 三套独立飞控 + 投票仲裁；多传感器交叉比对；故障通道被隔离后由剩余通道维持控制。[1]
导航定位GNSS 丢失 / 漂移 / 多路径偏差城市峡谷遮挡、信号干扰、设备故障位置与航线判断错误，偏出预定空域S3 较重 多传感器融合定位；预设航线与地面监控；异常时进入等待 / 迫降程序。
数据链路中断、超时、误码或被入侵遮挡、电磁干扰、设备故障、网络攻击地面失去监控与干预能力；存在非法控制风险S4 严重 链路状态纳入健康监控；自主飞行不依赖持续遥控；需补充链路冗余、加密与网络安全验证。
机体结构承力件损伤、连接松动、部件脱落疲劳累积、维护缺陷、撞击损伤结构完整性下降，可能危及飞行安全S4 严重 碳纤维结构设计；定检与维护程序；适航状态由 AC 与质量体系约束。
气象超出边界风速 / 降雨 / 能见度超出运行限制天气突变、预报偏差、运行决策失误姿态保持与操纵裕度下降，偏航或迫降S3 较重 运行气象限制与放飞标准；地面站气象监控；超限天气不安排飞行。
乘员约束 / 撤离座椅 / 约束失效，舱门开启异常设计缺陷、磨损、误操作、冲击过载乘员受伤，应急撤离受阻S3 较重 F1 风格乘员座椅与舱门设计；应急程序与乘员安全说明；具体约束强度以审定数据为准。[2]

故障树分析（FTA）Fault Tree Analysis

以最严重后果为顶事件，自顶向下分解为六类一级原因，再展开到底事件。FTA 用于识别共因失效与关键路径，判断哪些底事件会通过不同分支汇聚到同一顶事件。

顶事件：航空器失控 / 坠机，导致乘员或地面人员伤亡

Top event: loss of control / crash with fatal consequences

动力推进失效

  • 单 / 多电机停转或失控
  • 桨叶断裂 / 桨距异常
  • 电池组失效或供电中断
  • 推进通道共因故障

飞控航电失效

  • 多通道同时故障（共因）
  • 投票仲裁失效 / 软件缺陷
  • 航电供电或总线异常
  • 错误指令未被识别排除

导航感知失效

  • GNSS 丢失 / 干扰 / 漂移
  • 高度 / 姿态传感器故障
  • 多传感器数据矛盾未融合
  • 位置偏差进入危险空域

通信链路失效

  • 链路中断地面失去监控
  • 链路延迟 / 误码导致误判
  • 非法入侵或指令欺骗
  • 冗余链路同时失效

环境诱发

  • 大风 / 湍流超出操纵裕度
  • 降雨 / 低能见度影响判断
  • 鸟击或与其他航空器碰撞
  • 起降场地条件不足

后果扩大因素

  • 迫降区域地面人口密集
  • 降落伞 / 应急设备未生效
  • 乘员约束与撤离失效
  • 维护 / 调度隐患前置引入

关键共因路径（需重点审查）

  • 共用电源 / 母线异常同时影响多组动力或航电。
  • 共同软件版本缺陷可能在多飞控通道同时触发。
  • 同一环境干扰源同时压制主备导航 / 链路信号。
  • 结构连带损伤使相邻旋翼 / 电机相继失效。

阻断思路

  • 物理与电气隔离，降低共因耦合。
  • 通道异构 / 独立供电，避免同源失效。
  • 底事件探测与自动隔离优先于人工介入。
  • 末端以迫降场地选择与降落伞控制后果。

关键风险专题Key Risk Topics

R-1

动力电池热失控与空中起火

风险机理

航空电池在空中无法像地面车辆那样靠边停车；单体短路、过热引发热失控后，可能沿组内蔓延，造成动力丧失与烟雾火灾。电池能量密度与热安全在行业内长期存在权衡。

缓解与缺口

分组供电、故障隔离与健康预警是已有措施；热失控不蔓延验证、高温环境循环寿命、撞击后电池完整性仍是需持续积累证据的关键项。

R-2

单 / 多动力单元失效与容损边界

风险机理

分布式旋翼为单失效提供推力补偿裕度；但失效单元数量超过容损设计边界，或出现共因 / 连带失效时，剩余推力不足以维持安全悬停与着陆。

缓解与缺口

公开资料显示单动力单元失效试验已通过；多单元失效、不同载重与气象条件下的容损包线，需要更完整的试验与数据披露支撑。[11]

R-3

导航干扰、城市峡谷与定位偏差

风险机理

楼宇遮挡、信号反射造成多路径，或人为 / 电磁干扰使 GNSS 降级；若融合定位未能及时识别，可能出现航线偏离与高度判断错误。

缓解与缺口

多传感器融合与地面监控为基础措施；复杂城市场景下的定位完好性监测、干扰识别与降级策略，是城市 UAM 落地前需要补足的能力。

R-4

数据链路中断与网络安全

风险机理

链路承担状态回传与监控职能；中断会使地面失去态势掌握，延迟与误码影响判断；开放链路还面临入侵、欺骗与非法指令风险。

缓解与缺口

自主飞行不依赖持续遥控是天然隔离；链路冗余、加密认证、异常指令识别与网络安全渗透测试，应作为运营准入的明确审查项持续验证。

R-5

气象边界与运行窗口

风险机理

多旋翼抗风能力、降雨与能见度容忍度有限；天气突变或预报偏差可能使航空器进入操纵裕度不足的状态。

缓解与缺口

以放飞标准、气象监控与停飞规则控制边界；运行数据积累有助于细化各工况安全包线，但不宜在边界天气下追求班次密度。

R-6

迫降场地与地面第三者风险

风险机理

一旦需要迫降，下方地面人员与财产构成第三方风险；景区、城市边缘与人口稠密区的后果差异显著。

缓解与缺口

航线规划避开人口密集区、预设应急降落点、降落伞降低坠落速度；地面风险评估应纳入航线审批与运营方风险管理制度。

R-7

空中碰撞：鸟类与其他低空飞行器

风险机理

低空环境内鸟群、其他无人机与有人机均可能进入航线；旋翼 / 机体被撞击后可能产生结构损伤或动力失效。

缓解与缺口

空域申报与隔离飞行降低冲突概率；探测、避让决策与空域交通管理协同，是扩大运行范围后必须强化的环节。

09

冗余—缓解—残余风险映射Redundancy, Mitigation and Residual Risk

将危险源、设计冗余、验证 / 运行措施与仍需关注的残余风险逐项对照，便于判断安全措施是否闭合。

单电机 / 旋翼失效分布式动力 + 推力重分配单动力单元失效试验；健康监控[11]多单元 / 共因失效边界；高载重与大风工况裕度

10

SOTIF 与未知风险Safety of the Intended Functionality and Unknown Risks

传统故障安全关注"部件坏了怎么办"；预期功能安全（SOTIF, ISO 21448）进一步关注"部件没坏，但功能在局限或边缘场景下不足"的风险。对自主飞行 eVTOL，后者同样关键。

可能的 SOTIF 关注点

  • 感知与决策在罕见天气、复杂背景下的识别局限。
  • 航线规划未覆盖的非常规障碍物或临时空域变化。
  • 自主算法在边界工况下的行为难以穷尽预演。
  • 人员（乘员 / 调度）对自动化系统预期不匹配。

数据与成熟度缺口

  • 运行样本与飞行小时仍在积累，长期可靠性数据有限。
  • 跨季节、跨地域（含高寒、高湿、大风）工况覆盖不足。
  • 公开失效 / 事件细节有限，不利于外部独立复盘。
  • 公众安全信任需要长期、透明的运行记录建立。
SOTIF 结论 已取证证明设计在审定场景内达到安全基准；未知与边缘场景风险需要通过运行数据闭环、场景库扩展、事件复盘与持续适航管理逐步收敛，而不能由单次演示或认证状态自动消除。
11

安全改进建议与运行限制Recommendations and Operational Limitations

01

细化并公开容损包线

补充不同载重、风速、温度下的单 / 多动力失效验证结果，明确可安全返回与必须迫降的边界条件，作为运行手册依据。

02

强化电池航空级安全验证

推动热失控不蔓延、撞击后电池完整性、高温循环寿命等专项验证；建立电池全寿命健康档案与更换判据。

03

完善链路冗余与网络安全

明确主备链路切换逻辑，补充加密认证、异常指令识别与渗透测试；将网络安全纳入运营准入与持续监控。

04

建设场景化运行限制

坚持昼间、良好气象、隔离 / 低冲突空域与预设航线运行；明确风速、降雨、能见度上限与放飞 / 停飞判据，不超边界排班。

05

落实地面风险与迫降管理

航线避开人口密集区，预设应急降落点；把地面第三者风险纳入航线审批与运营方风险评估，定期复核迫降场地可用性。

06

建立数据闭环与持续适航

收集飞行小时、告警、失效与事件数据，形成场景库与改进闭环；对维护、调度与乘员宣传保持可审计的程序记录。

总体安全判断 EH216-S 通过多套飞控、分布式动力、全备份、健康监测与降落伞形成了多层次安全架构，并完成了中国载人 eVTOL 领先的取证与商业运行验证。其安全水平应理解为"在批准的运行边界内可控"；面向更复杂城市运行，仍需在电池安全、容损包线、导航完好性、链路网络安全与地面风险控制上持续积累证据。
